# Customer Default Risk Prediction

An exploratory data analysis and machine learning project focused on predicting credit card default among customers of a Taiwanese bank.

## Project Overview

This project analyzes credit card customer data to identify patterns associated with default risk and develops machine learning models to predict whether a customer is likely to default.

## Dataset

The dataset contains information about credit card customers, including demographic characteristics, credit information, payment history, and bill/payment amounts.

The target variable indicates whether a customer defaulted on their credit card payment.

## Methodology

The analysis follows these steps:

- Data cleaning and preprocessing
- Exploratory data analysis
- Feature analysis
- Data visualization
- Model training
- Model evaluation
- Feature importance analysis

## Key Analysis

The project explores relationships between customer characteristics, payment history, credit limits, and default behavior.

Visualizations include:

- Correlation matrix
- Model confusion matrix
- Feature importance

## Machine Learning

The notebook contains the machine learning models used to predict customer default risk.

Model performance is evaluated using appropriate classification metrics.

## Results

Model performance and key findings are presented in the Jupyter Notebook.
